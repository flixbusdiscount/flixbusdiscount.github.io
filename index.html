FAQ

Questions before you order.

When do I receive the code?

The code is shown on the success page after Stripe confirms the checkout session is paid.

How do I apply the code?

During your FlixBus or Greyhound booking, go to the shopping cart, enter the code in Enter Voucher, and click Redeem to apply it.

Is this an official FlixBus or Greyhound website?

No. This is an independent store. It should not be represented as an official FlixBus or Greyhound property or reseller without written authorization.

What if my code does not work?

Contact support with your Stripe receipt and order session ID. The store owner should verify the issue and either provide a working replacement code or refund the order according to the refund policy.
