Refund policy

Refunds and replacement codes.

Last updated: August 14, 2026

RideCode Deals sells digital voucher codes for FlixBus and Greyhound. This policy explains when we refund, replace, or decline a refund. It does not limit any mandatory consumer protection rights that apply in your location.

Quick summary

  • If payment succeeds but no code is delivered, we will deliver the code, replace it, or refund the order.
  • If a code is invalid when first redeemed as instructed, we will replace it or provide a 100% refund.
  • If you accidentally order twice and the extra code was not revealed or used, we will refund the duplicate order.
  • After a working code is revealed, the order is generally not refundable unless required by law.
  • Approved refunds are returned through Stripe to the original payment method.

Refund or replacement eligibility

  • The checkout completed, but the confirmation page did not reveal a code.
  • The code was already used before your purchase.
  • The code is rejected when entered in “Enter Voucher” and Redeem is clicked.
  • The code materially differs from the offer shown at checkout.
  • The charge was duplicated because of a technical or accidental checkout issue.

Usually not refundable

  • The code was successfully redeemed or used.
  • You changed your mind after the code was revealed.
  • You no longer need to travel or found a cheaper ticket elsewhere.
  • You entered the code somewhere other than “Enter Voucher” or did not click Redeem.
  • The issue is caused by a carrier rule, account issue, route issue, outage, or checkout restriction outside our control.

Digital delivery and cooling-off rights

If your local law gives you a cancellation or cooling-off right for online digital purchases, you can ask to cancel before the code is revealed or used. Once you ask us to reveal the code after payment, digital delivery begins. Refunds are still available when the code is invalid, not delivered, materially different from the offer, or when mandatory law requires a refund.

How to request help

Email flixbusdiscount@gmail.com as soon as possible. Include your Stripe receipt, checkout session ID, order date, the route or trip you tried, and a screenshot of the error message if redemption failed.

Review and payment timing

  • We aim to review complete requests within 2 business days.
  • Approved refunds are submitted within 3 business days after approval.
  • Your bank, card network, or payment provider may need additional time to post the refund.

RideCode Deals is an independent store and is not affiliated with FlixBus or Greyhound. This policy is a customer-service policy, not legal advice. If this policy conflicts with mandatory consumer law, mandatory law controls.
